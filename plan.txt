Maths Quiz Game

User connects to app. X

User shown list of currently running games. X
User given option to create game.
    Create game screen:
        set delay - how long before game starts?
        set game name
        set max players
        go -- instantiates new Game object

User joins game
    Game screen:
        User assigned colour
        Has game began? Yes
            Server generates questions
            Questions sent to clients
            Users provide answers
            Answer sent to server
            Server checks answer
            Results sent to clients
        No:
            countdown displayed on screen
            user lists displayed on screen
